# 文献库与 PDF 阅读器样式约定

保留当前工作台布局、暖色表面和 Zotero 式紧凑论文列表。增加功能时先复用已有角色，避免为每个功能再建立一套字号或按钮。

## 字体层级

统一从 `src/theme-tokens.css` 取值，`src/port/ui-primitives.css` 提供跨页面及 Portal 的基础样式。

| 用途 | Token / 约定 |
| --- | --- |
| 按钮、表单、菜单、状态文字 | `--ui-font`：13px / 1.4，常规字重 |
| 论文行中的期刊评级、研究标签及溢出计数 | `--ui-font`：与阅读状态同为 13px / 1.4，常规字重 |
| 标签页、元信息、辅助文字 | `--ui-font-small`：12px / 1.4 |
| 计数、细节标记 | `--ui-font-caption`：11px / 1.4 |
| 摘要、笔记、批注正文 | `--ui-font-prose`：14px / 1.75 |
| 分区标题 | `--ui-font-section`：13px / 600 |
| 弹窗标题 | `--ui-font-dialog`：20px 衬线字体 |
| 页面标题、论文标题 | 沿用工作台现有衬线标题层级 |

界面统一使用 `--font-sans`；中文使用同一系统回退链。不要在某个弹窗或菜单里单独指定宋体、微软雅黑或通用 `sans-serif`。PDF 页面由文档字体渲染，翻译正文遵循用户字号设置，不应被界面规则覆盖。

## 控件

- 普通操作复用 `.rw-primary` / `.rw-secondary`：32px 高、13px 中等字重、胶囊圆角。
- 独立图标操作复用 `.rw-icon-button`：32px 控件、16px 图标、8px 圆角。
- 轻量行内操作复用 `.rw-text-button`。表格内图标、状态胶囊、标签页等保留各自的紧凑尺寸，不能用全局按钮高度覆盖。
- 菜单使用共享表面、字体和圆角；挂到 `body` 的菜单和弹窗也必须生效，不能只依赖 `.rw-workbench` 祖先。
- 默认字体继承规则使用低特异性 `:where(...)`。不要添加 `.rw-workbench button { font-size: ... }` 之类会压过组件字号的规则。
- 表格所有列名共用 `.rw-column-heading`：相同字号、常规字重、左对齐和留白。排序仅显示方向箭头，不为排序列另设底色或加粗；年份列名、年份和缺失占位符统一左对齐，使用等宽数字。
- 颜色反馈、禁用状态和键盘焦点使用已有变量。窄屏可增加触摸面积，字号仍保持同一层级。
- 导入引擎的适配放在 `src/port/reader.css` / `theme.css`，不修改 PDF 渲染引擎。只有原引擎已经使用 `!important` 的尺寸才在适配边界作有注释的覆盖。

控件的名称放在 `aria-label` / `title`，不要为了说明操作往页面增加提示段落。

阅读状态使用共享 `--ui-font`，普通行、选中行、详情、菜单与阅读器保持同一字体、字号和常规字重。悬停只改变底色，不对整个胶囊使用 `filter`、文字阴影或缩放，避免文字随反馈变暗或进入不同的合成图层。检查字号之外，也应检查中文实际回退字体，以及选中 / 悬停状态下的文字颜色和渲染效果。

备注列沿用表格文字与 30px 行高，未编辑时只显示文本或缺失横线，不增加常驻编辑图标或说明。原位编辑器高 26px，使用共享 UI 字体与单一焦点边框；普通文字焦点框内收，避免被表格单元格裁成两条竖线。窄屏备注位于标签下方，空值不额外占行。

备注胶囊使用共享 13px / 400 / 1.4 字体，24px 高，与阅读状态采用同一文字规格。颜色仅用于标记内容，保持浅底、细边和深字，选中行也保留其文字对比。自定义值只接受十六进制颜色，自动调整深字以达到至少 4.5:1 对比；不把备注当 HTML 或 CSS 执行。原始语法保存在 `note`，显示解析不生成另一份数据，也不向正常界面增加语法说明。

详情备注位于顶部标签与阅读 PDF 按钮之间，保持原有头部暖色底，不增加卡片或工具栏。小标签沿用辅助文字角色，正文使用共享 UI 字体并换行，胶囊在窄面板也可折行。点击进入至少三行的编辑框，支持纵向调高；失焦保存，Enter 换行，Ctrl/Cmd+Enter 或 Ctrl/Cmd+S 提交，Esc 取消。与列表复用同一组件及字段，交替编辑从最新待写入值开始，不把旧模型内容覆盖回去。

## 验证

```sh
npm run build
npm run audit:research-ui
```

检查使用生产构建和独立浏览器存储，不读取用户文献库。它比较文献库、详情、菜单、设置、PDF 工具栏、统计浮层、翻译浮窗和批注弹窗中同类控件的实际样式，并保存 1440、768、390px 截图及越界检查。报告与截图位于 `.taste-skill/ui-consistency/`；样式不一致或页面错误时命令返回失败。

样式审计不能代替人工看图。修改后检查三个宽度的标题、动作组、菜单、侧栏，确认没有裁切或文字换行异常；涉及交互再运行相应的现有 Playwright 流程。


研究笔记使用 `ResearchNotes` 共享组件，文献详情、独立写作窗口与 PDF 并排面板共用 `app.paperNotes` 会话。UI 控件仍为 13px、32px 高度、16px Lucide 图标；正文单列最大 800px，使用 16px / 1.85 无衬线，标题为 26 / 22 / 19 / 17px，代码单独使用等宽字体，公式保留 KaTeX 字体。正文与 UI 是不同语义角色，不用控件字号覆盖正文，也不全局覆盖 `.vditor-reset`。原 PDF 批注不复用研究笔记数据或编辑器。

研究笔记工具栏为 44px 单行：文档操作通过 portal 合入 Vditor 原工具栏，保留格式事件；不通过复制编辑器按钮逻辑重做排版。窄屏使用横向滚动，菜单固定定位脱离裁切。按钮保持统一 32px/16px，源码模式沿用同一行高；保留已有可访问名称与键盘快捷键。

特殊标记颜色只用于笔记内容及预览；工具栏与样式面板复用现有 UI 字号、按钮和边框。`note-styles.css` 对编辑区和预览分别限定作用域，不覆盖全局块引用、span 或 mark。八类 Callout 使用低饱和填充和语义色，外观以 type / type-outline / type-soft 保存在 Markdown 中；行内 HTML 样式通过双向适配保留，运行时元数据不得导出。

Callout 默认色变量的选择器必须弱于各语义类型，避免预览有颜色、正文却全为灰色。标题使用 15px / 600，18px 本地 SVG 轮廓图标，通过 CSS 蒙版呈现，不进入 Markdown 正文；正文沿用笔记字体。保持 2px 侧线、浅底和合理段间距，只有标题时不保留空正文间距。代码块中的示例只通过用户明确的“转为标注块”操作转换，不因内容看似 Markdown 而自动改写普通代码。

正文 / 附录对照使用原阅读器的两份独立实例，不复制渲染、选择或标注逻辑。栏头 38px，选择器使用 `--ui-font`，关闭操作复用 32px / 16px 图标按钮；原工具栏继续保持单行。8px 分隔线可拖动、键盘调整及双击均分；内容区域不足 680px 时上下排列。布局尺寸变化应保留页内滚动位置，手动缩放不被分栏调整覆盖。样式审计包含两栏字体、按钮以及 1440 / 768 / 390px 对照截图。

笔记/PDF 定位操作复用现有单行工具栏，链条与双向箭头均为统一 32px 控件、16px Lucide 图标；PDF 框选插入使用阅读器原图标按钮。关联放在右键菜单与标题选择弹窗，不增加常驻说明栏。标题的小来源标记保持 13px 控件字体，正文与标题字号不受影响；当前位置只用淡侧线，原文区域短暂细边突出。截图在当前块后独立成块，不嵌套进标题或原文链接。来源位置保存在 Markdown 链接，标题改名、段落移动、模式切换与导出都保留。滚动只读取定位链接及可见区域，不在滚动或输入事件中序列化整篇笔记；仅明确修改图片关联时通过编辑器 API 规范化一次文档，并保留撤销边界。

科研课题工作区复用共享字体、颜色、32px 胶囊动作及 16px 图标，使用暖底目录、白色正文与紧凑灰白表格，不增加说明栏或大面积统计卡片。六个页签采用与文献库相同的细下划线；状态使用 13px / 400 胶囊，主要和次要动作均为 500 字重。原生 select 的行高由平台决定，单独比较字族、字号和字重，胶囊文本仍检查完整文字角色。

课题目录和内容在窄屏分开显示，页签横向滚动；论文表格保留标题宽度，在自身容器内滚动。点子、实验与课题正文复用 ResearchNotes，保持单行工具栏和相同的正文排版；课题没有 PDF 上下文时不显示定位或联动按钮。React StrictMode 的首次探测挂载必须在初始化编辑器前取消，避免迟到的实例清空当前编辑区。弹出菜单外壳使用 body 下的明确角色选择器，防止共享 CSS 提取顺序让底色退回纯白。

`npm run audit:topics-ui` 在生产构建中导入合成论文及课题数据，比较课题与文献库的实际文字、状态、表格和动作样式，并保存六个页签与运行弹窗的 1440 / 768 / 390px 截图。报告位于 `.taste-skill/topics-ui/`，只使用独立浏览器存储。

单课题默认采用紧凑研究长卷；任务表模式保留可调宽详情的双栏。课题资料仍由独立入口进入。任务状态、正文 UI 和页签使用共享 13px / 400；动作使用 13px / 500、32px 高度和全圆角。类别标签、结构化字段与记录来源分别使用 12px、12px 和 11px 次级角色，不把正文缩成元数据。任务和课题标题使用现有衬线字体。双色字段胶囊以完整键值对换行，长路径与网址可折行，完成节点与检查通过使用绿色。

任务界面容器宽度不足 1450px 时，日期移到任务标题下方；不足 1001px 时列表与详情分屏；手机使用带时间、标签与状态的紧凑条目，页面不横向溢出。详情分隔线支持拖动、方向键和双击重置，宽度保存在本地。不得为了适配窄屏增加常驻说明段落。

`npm run audit:tasks-ui` 使用生产构建与独立合成任务，比较文献库与任务界面文字/按钮角色，检查 1737 / 1440 / 768 / 390px、四个详情页签与模板弹窗。安装 design-taste-frontend 技能时额外运行其浏览器探针；探针只读取第一个 h1 的限制由实际可见标题测量补足。报告在 `.taste-skill/research-tasks-ui/`。

多课题入口沿用同一工具栏与任务布局。总览使用紧凑课题行和右对齐计数，默认不预选任务，不新增统计卡片或说明段落；选择任务后再展开详情。顶部总览入口在手机上收为同尺寸图标，课题选择器与动作仍为一行。右侧的小课题来源可返回对应任务表。新建任务和 Prompt 的课题选择使用现有字段控件，粘贴预览明确展示归属课题。

课题目录采用紧凑行与可折叠表头，行末操作使用统一的 32px / 16px 中性图标；重点课题优先，但不添加统计卡片或常驻提示。目录过长时在自身区域滚动，手机沿用相同层级。任务详情的关闭按钮仅在桌面显示，窄屏继续使用返回按钮；无详情的桌面表格展开日期列，保持表头与数据对齐。移动弹窗复用现有字段和胶囊动作，长任务名不挤压目标选择器。生产 UI 审计的数值尺寸比较允许 0.01px 浮点误差，字体、字号、字重、圆角等文本值仍严格比较。

研究笔记在新段落输入 `/` 或 `\` 呼出插入菜单；沿用共享 13px UI、32px 选项和 16px Lucide 图标，不新增常驻工具栏或说明文字。浮层挂载到当前文档 body，按光标位置在可视区内向上或向下展开；键盘焦点保留在正文，用方向键、回车和 Esc 操作，中文组合输入期间不处理候选键。路径、代码、公式、链接和表格/列表内部的反斜杠保留字面含义。筛选只读取当前段落，不转换整篇 Markdown；插入复用 Vditor Markdown、保存和撤销链路。原始源码模式仍保留直接编辑。生产审计包含 1440 / 768 / 390px 菜单的字体角色、边界与截图。

公式兼容层在 Markdown 导入、HTML 粘贴与当前块自旋阶段识别 `\(...\)` / `\[...\]`，转为原生可编辑公式；保留现有 `$...$` / `$$...$$` 与 KaTeX 字体，不使用 UI 字体覆盖数学排版。旧笔记中只有整段方括号且包含明确 TeX 命令的公式可恢复；普通引用、括号、链接和代码不推断为公式。公式弹窗接收裸 LaTeX 或完整分隔符，并恢复原选择位置；块插入清除空壳段落，避免其他视图规范化空行后重置本视图的撤销历史。KaTeX 尚未完成的预览按其公式源码记录历史，不能将空预览存为撤销状态。没有数学候选时快速返回，不在输入事件中转换全文。


单课题的「脉络」沿用暖底、共享 13px / 400 UI 与 32px 胶囊动作。所有节点收起约 35px 高，时间、标题、类型、标签、记录数和状态同行；时间列为 11px 等宽数字，类别标签 12px，记录计数 11px；关键节点和版本快照仅对标题使用 15px 衬线层级。关系线测量真实 DOM 位置，用 1.4px 中性绿线表示结构，选择节点时仅突出其上游路径。树不采用满屏方框、彩色连线或常驻使用说明。

节点可自由命名类型，选择普通 / 关键 / 版本快照，快照可填写版本。多前置节点表示汇合，分支可折叠；只有全部前置路径都被折叠时才隐藏后续，保留从另一条路径汇合的节点。「只看主干」与搜索、状态筛选叠加，隐藏中间节点时沿现有依赖连到最近可见祖先。旧任务没有关系时保留独立时间节点，不能凭创建顺序伪造依赖。

详情原位展开，复用同一 TaskDetail 的时间线、附件、论文、Markdown 和讨论；不复制数据或编辑器，收起及切换任务表仍由同一记录驱动。新增与导入后定位到选中节点，常规编辑不反复滚动。跨课题总览保留任务表，视图偏好保存在本地。复制课题重映射关系；一起移动的节点保留内部依赖，移动和删除清理悬空关系。Prompt 列出稳定节点 ID 并支持类型、版本及关系字段，追加事件不改变已有依赖。

`npm run audit:lineage-ui` 用独立合成数据检查生产构建的实际字体、动作、普通节点密度、关系线及 1440 / 768 / 390px 排版。报告在 `.taste-skill/research-lineage-ui/`；继续运行 `audit:tasks-ui` 验证任务表及已有管理功能。设计探针的 tiny-text 来自时间、来源和标签等既定次级角色，正文仍为 13px；icon-chips 来自沿用的全局导航和状态控件；tabular 探针偏向表格数据，本视图的 time 元素显式使用等宽数字。


树的宽度指左侧分支轨道，不是整个正文内容区。拖动手柄放在轨道与标题之间，仅改变轨道横向间距；正文保持全宽自适应，不读取旧的 `research-lineage-width`。新的偏好保存在 `research-lineage-track-width`，双击恢复随分支数计算的默认值，方向键每次调整 8px；轨道限制为 48–400px，窄屏最多占内容宽度四分之一。折叠按钮与拖动区分开，连线根据真实节点位置重算。分隔线跟随树的实际内容高度，不在右侧空白处生成整页边框。

单行布局以长卷自身作为容器断点；空间不足时标题省略并保留完整可访问名称及悬停文本，次级标签移入展开详情，不能为了显示全部字段再次变成常驻双行。轨道调整通过现有 ResizeObserver 重量连线，不修改任务数据或重建编辑器。


长卷主轨道只表达研究节点与节点之间的关系。TaskDetail 复用原数据与编辑操作，展开时仅占所属节点的正文列，用轻微内缩、浅底与安静的左侧边界标示内容归属。过程记录的时间、标题和字段全部收在该区域，不能跨到树的时间列或绘制轨道圆点/连线。真实子节点仍在外部主树上。录入时间与时间依据按需查看，未知发生时间不能用补录时间代替；事件按实际发生时间排序，未知时间放末尾。

描述保持轻量，元信息、备注与前置链接按需展开；事件字段使用可换行的双色胶囊。节点标题与叶节点通过字重、实心/空心图形区分，分支正文轻微内缩，合流仍回到主干；不为每级深度累积无限缩进。SVG 只测量真实节点，展开、原位编辑与宽度变化后连线必须仍指向真实子节点。过程内容不能成为拖动或插入的落点。动效沿用下方 Motion 规范，尊重减少动态效果。


长卷展开采用固定的「时间 / 记录标题 / 字段」阅读列，桌面记录默认约 35px，字段只在自己的列内换行。标题后的轻量箭头展开描述、录入来源与时间依据；这些信息保留原始值，但不默认占据每条记录一行。窄屏将字段放到标题下，菜单保持右侧对齐。字段胶囊使用暖中性配色，完成或检查通过才使用绿色。

展开工具栏只保留单行摘要、一个 32px 内容选择器和追加记录动作。选择器切换过程、文件、关联、讨论、备注与节点信息；不再同时铺开四页签、元信息和底部工具行。备注只在明确选择备注时显示编辑区，切换视图必须先保存草稿，不能仅依赖 textarea 的失焦。Prompt 和接续沿用节点右键/更多菜单，前置链接放在节点信息中。任务表详情保留原布局。


轨道圆点是 24px 可聚焦操作目标，外观仍为原 6–10px 圆点/菱形；点击或右键打开接续、并行分支、编辑、移动与删除菜单。真实依赖线段使用透明加宽的独立 SVG 命中层，悬停出现小加号；由筛选跨越隐藏节点得到的虚拟线段不可插入。节点与命中线的层级不得遮挡分支折叠或轨道宽度手柄。

拖动圆点到其他节点表示接续，拖到线段表示插入，临时「独立节点」落点只在拖动时出现。拖动中显示紧凑位置预览、高亮合法落点，非法循环显示原因但不得落库；空白释放和 Esc 取消。边缘自动滚动只作用于长卷滚动区，指针释放不得误弹菜单。键盘与触屏可通过同一个节点菜单的移动弹窗完成关系调整。

所有结构修改以当前存储重新校验并一次保存。移动仅针对一个节点，原来的直接后续接回其原前置；插入仅替换指定边，合流的其他前置不变。删除保留后续工作并去重接回，沿用删除确认。原始创建、发生、补录时间和业务内容不作布局调整；可选 lineageRank 只记录视觉排序，并遵守拓扑约束。尚无后续编辑时提供一次撤销，不能覆盖用户后来写入的数据。

动效使用本地 Motion React（依赖版本见 package-lock）：布局采用 240ms 位置过渡，展开采用 200ms 高度/透明度过渡，增删使用 AnimatePresence；不增加弹跳和发光装饰。图形测量在移动期间短暂逐帧跟随实际圆点，结束后停止；与尺寸/内容观察共用同一个 RAF 调度，不能叠多个永久测量循环。尊重减少动态效果，保留直接操作反馈。生产审计包含节点菜单、连线加号、拖动预览以及 1440 / 390px 移动弹窗。

新课题不能只显示「暂无节点」。长卷首行使用真实轨道列与正文列呈现「＋ 创建首个节点」，沿用正常行的位置；空课题隐藏无效的只看主干。已有长卷每行保留常显的 24px 子节点加号，短菜单只提供接续与并行分支；末尾提供独立节点入口。筛选无结果和课题真正为空必须区分，前者提供清除筛选，不能误导为首次创建。

长卷创建/编辑窗口与按钮统一使用「节点」，任务表保留「任务」语境。由长卷创建时锁定当前课题，用紧凑关系条呈现独立、接续、分支或插入的目标；前置选择器收在「调整接续关系」。每次新建重置原有父节点、并行与插入状态，取消后不得污染下一次创建。保存后在同一长卷选中并展开新节点，直接追加过程记录；不添加教学段落。

长卷的日常创建、编辑与进展追加使用原位编辑器，不再打开节点/事件弹窗。双击节点标题或菜单编辑时，输入框替换该行正文；点击进展标题，在该进展的位置编辑。默认只展示标题、描述和紧凑保存/取消图标，节点属性与事件模板按需展开。描述单独点击即可修改，失焦保存，Esc 取消；完整编辑器使用确认图标或 Ctrl/Cmd+Enter 保存，Esc 取消，输入法确认不得误提交。

收起节点/切换视图保留当前会话的临时编辑草稿，显式取消或保存后清除；草稿不宣称跨刷新持久化。编辑从当前存储读取节点，合并保留已有事件和关联内容。未修改时间控件时必须保留原始毫秒精度，不能因分钟级输入框截断发生/创建时间；来源、录入时间和模板快照继续保留。

展开状态的过程操作使用 24px 轻量文本动作与无描边内容选择器，不再重复显示记录数量或黑色追加按钮。默认记录行不展开来源；通过记录菜单按需查看。仅折叠手动创建器生成的空「创建任务/创建节点」记账事件，保留原始存储，并在节点信息中可见；有字段、正文、模板、时间依据、状态或外部来源的同名事件必须保留。新建节点以节点元数据记录起点，不强制添加空过程条目。任务表仍使用原有完整表单。


展开内容的可访问区域通过节点标题命名，标题控制只负责所属内容的开合，分支折叠继续控制真正的后续节点。窄屏记录优先保留时间与标题同行，字段在正文内部换行；编辑器可将日期独立一行以保留输入宽度。禁止给过程记录重复附上树节点的图形。
