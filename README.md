## 为什么做 Research Workbench？

科研信息很容易散落在项目表、日历、待办软件和零碎笔记中：项目进行到哪一步、当前主攻什么方向、下一个截止日期是什么，往往需要在多个地方反复查找。

Research Workbench 不试图替代文献管理器、实验平台或文件系统。它更像一张始终放在桌面的科研控制台，把每条研究线索的当前状态、背景记录和下一步行动放回同一个上下文中。

| 常见的碎片化状态 | Research Workbench 中 |
| --- | --- |
| 纵向、横向项目分散在不同表格 | 在「科研课题」中按纵向 / 横向统一分组 |
| 研究方向只有标题，缺少过程记录 | 用正文、自定义字段和主次方向持续维护 |
| 待办、截止日期和日程彼此割裂 | 待办分组、周日程和总览提醒集中呈现 |
| 数据位置、心得与复盘散落 | 用可定制的记录类型统一登记 |
| 不希望科研数据默认上云 | 本机存储，并支持手动导出 JSON 备份 |

## 功能一览

### 原 Obsidian 插件迁移版

本分支接入用户提供的 Research Library 0.10.0 与 MuPDF Reader 0.10.4 的数据与阅读能力，通过独立宿主适配文件、Markdown/YAML 与工作区接口，不需要运行 Obsidian。文献库重新实现为原生三栏界面，沿用工作台的米色与衬线标题，不再将原插件表格作为主界面；原插件源码指纹见 `src/migrated/PROVENANCE.json`。

文献库与其他模块共用配色、字体、深色标题栏及主导航；切换模块保持侧栏的收纳状态。页内分类用于阅读队列、文献集与研究主题，搜索与导入位于统一的页面顶栏。共享视觉变量位于 `src/theme-tokens.css`，字体入口为 `src/fonts.css`。

论文详情的「标签」区域支持添加和直接移除标签，也可右键论文选择「编辑标签」或双击列表标签列。输入支持回车、逗号、分号和批量粘贴，已有标签可直接选择；Ctrl 多选后可批量添加或移除，按差量修改各篇论文的 `keywords`，保留各篇独有标签和其他元数据。标签保存后参与列表展示与搜索，取消编辑不会写入；批量编辑中的计数表示该标签覆盖了多少篇所选文献。

文献库采用 Zotero 式紧凑桌面表格：30px 单行、无衬线正文、灰白交替底色、蓝色选中态，标题前显示附件图标与星级。标题、影响因子、出版物、创建者、年份、阅读状态、期刊评级与标签独立对齐；SCI、中科院分区和 CCF 合并显示在期刊评级列，研究主题与关键词单独显示在标签列；点击标题、影响因子、出版物、创建者或年份表头切换升降序。紧凑模式为 26px。拖动表头右边界可调整列宽，双击边界恢复该列默认宽度；表头右键或工具栏“选择显示列”可勾选列，标题固定显示。宽度与显隐设置保存在当前设备，重开后继续使用；菜单也支持恢复默认列布局。出版物列与详情自动将已识别的会议全名显示为标准缩写（如 NIPS 统一为 NeurIPS），arXiv 名称、来源链接和 DOI 写法统一显示为 arXiv。悬停可查看原名，编辑、指标匹配与导出保留原始来源；检索兼容缩写与全名，联合会议及 Workshop/Findings 不混为主会。阅读状态采用带图标的彩色胶囊和自定义弹出菜单，列表、详情与 PDF 阅读器保持一致；支持方向键、Enter 和 Escape 操作。状态包括待整理、待阅读、阅读中、已完成与已归档，可在列表状态列、详情或 PDF 阅读器内修改，并可多选批量设置、按状态筛选及从归档恢复。PDF 成功打开后，待整理与待阅读自动变为阅读中；已完成、已归档与原本阅读中的记录保持状态，损坏或打开失败的 PDF 不触发自动修改。首次开始与首次读完日期按设备本地日期记录，批量操作遵循同一规则；重读或重新排队保留原日期。列表不再显示复选框：单击选中一篇，Ctrl/Cmd＋单击增减选择，Shift 连选，Ctrl/Cmd＋A 全选当前结果，Escape 取消。方向键导航、Shift＋方向键连选、空格增减选择同样可用；多选后显示批量状态与引用导出工具。筛选或切换分类会清理不再可见的选择，手机可从工具栏“多选文献”进入点按多选。详情默认收起，选中文献后显示信息、笔记和摘录，附件箭头可展开 PDF 子项，文档图标或双击条目打开原文。较窄窗口的表格在自身区域横向滚动，手机切为紧凑列表与独立详情页。

文献集层级：侧栏采用可折叠的文献集树，右键文献集可创建子文献集。拖至另一文献集中间可嵌套，上下边缘显示插入线并调整同级顺序，拖至“文献集”分组标题回到顶层；整棵子树一起移动，禁止放入自身或后代。右键另有上移、下移与移至顶层，左右方向键可展开 / 收起及返回父级。层级、顺序与折叠状态保存在 `research-vault/.workbench/collection-tree.json`，已有文献集兼容为根级；层级移动保留直接论文关联、PDF、笔记和状态，子级不自动给父级添加论文关联。重命名保留子级，删除单个文献集会将其子文献集提升一级。

库内拖拽分类：Ctrl/Cmd 多选（或 Shift 连选）后，拖动任一已选论文到左侧文献集即可批量添加；拖动未选中的行仅添加该篇。研究主题、科研课题同样支持。目标高亮并显示篇数，原有归属、状态与笔记保留；重复添加自动跳过，刷新后保留分类。拖到空白 / 智能视图或按 Esc 取消不会修改归属，也不会产生新导入标记。

导入归属与定位：在文献集 / 研究主题 / 科研课题中拖入或通过按钮选择 PDF，自动沿用当前类别；也可直接拖到侧栏的具体类别，目标会高亮。文件选择器保留打开时的目标，分类在保存笔记时一并写入。重复 PDF 不新建副本，而是追加目标关联、保留原分类及状态。导入完成后清除阻挡新条目的检索 / 状态 / 年份筛选，回到文献列表，当前批次临时置顶并滚动到顶部；手动更换排序后使用用户指定顺序。「本次导入」可单独查看这一批，也可关闭；新论文带「新」标记，打开详情后清除，未查看标记与批次入口在本机保留至多 24 小时。失败文件不产生新标记，刷新后仍可找回最近批次。

PDF 自动解析：导入后先保存原文件并按内容去重，后台读取 PDF 首页与内嵌标题、作者及明确的发表信息；有 DOI 时优先复用本库同 DOI 且标题一致的完整书目，否则查询 Crossref；有 arXiv 编号时查询 arXiv，标题检索只接受唯一的同名结果。先显示本地信息，网络失败可右键「重新解析文献信息」，详情显示识别结果；「更多文献工具」提供批量补全。旧版只按文件名创建且尚未解析的条目会自动补全；中断任务在重开后继续。原笔记在 `.workbench/metadata-backup/` 留存首份备份，保留手工字段、状态、评分和笔记，不改写 PDF。扫描版目前不含 OCR，识别失败会明确提示。在线查询只发送 DOI、arXiv 编号或候选标题，不上传 PDF / 笔记；识别到发表来源后沿用现有期刊指标自动匹配。

右键菜单：文献行支持阅读、编辑、研究笔记、状态 / 星级、添加分类、复制与导出引用、指标匹配和归档；右键已选条目保留多选并执行批量操作，右键未选条目切换为该篇。当前分类内可移除关联。侧栏分类支持导出、重命名和删除，删除分类保留论文 / PDF；阅读摘录支持定位、编辑、复制和删除。项目、方向、笔记、待办及日程也支持编辑、复制、状态、重点、工作区移动、归档与删除。删除操作先确认。支持 Shift+F10 / 菜单键、方向键、Enter、Escape；子菜单用左右方向键进入 / 返回，弹窗自动避开屏幕边缘。

论文详情宽度：拖动右侧面板的左边界调整宽度，双击边界恢复默认，调整结果保存在当前设备；收起再展开、刷新后继续使用。支持方向键微调、Shift 加速、Home 恢复默认及 Esc 取消本次拖动。宽度限制为 260–560px，并为论文列表保留至少 320px；手机端仍按整页显示详情。

阅读热图与逐页统计：标题背景可切换「时长热图 / 笔记热图 / 关闭热图」，颜色越深表示该页阅读更久或笔记更多，相邻页之间采用连续渐变，未记录页中心透明。阅读器顶栏「逐页统计」和详情中的「逐页阅读」提供每页时长、笔记数与跳页入口。笔记数汇总既有高亮、便签批注及截图摘录，不计不带页码的整篇研究笔记。时长从启用统计后开始记录，仅累计前台阅读；失焦、页面隐藏、休眠大间隔和连续 2 分钟无操作不计时。数据本地保存于 `research-vault/.workbench/reading-activity.json`，正常离开阅读器会保存，刷新时以本机临时检查点保留最后几秒。超过 240 页的标题热图按相邻页分组，逐页表格仍保留准确值。

已有本地 YAML 元数据中的 `impact_factor`、`jcr_quartile` / `sci_quartile`、`cas_zone` / `cas_partition`、`ccf_rank` 会显示为 IF、SCI、中科院和 CCF 标记，并参与搜索；可在文献信息编辑窗口补全或清除这些本地字段。影响因子数值配青色相对标尺，缺失显示“—”；不根据期刊或会议名猜测指标。

文献库顶栏的「自动匹配」支持批量补全期刊指标，并显示进度与逐篇结果。CCF 使用官方 2026 年第七版勘误目录的 677 条期刊 / 会议记录，支持常见缩写与别名，排除 Workshop、Findings、伴随会议和预印本，不按标题猜测来源。`scripts/build-ccf-catalog.mjs` 从官方 PDF 重新生成目录；数据文件保留版本、来源和页码。

easyScholar 在桌面版中配置 Secret Key 后可查询 IF、SCI / JCR 分区、中科院升级版分区和补充 CCF 记录。密钥在 Electron 主进程使用系统 `safeStorage` 加密，页面只读取是否已配置。在线请求按期刊名称去重、间隔至少 650ms，成功结果缓存 30 天、空结果缓存 1 天；错误不会缓存为空结果。查询只发送发表来源名称，需要补全来源时使用 DOI 查询 Crossref，不上传 PDF 或笔记。服务未提供指标年份时明确显示「服务当前返回版本」，不把当前指标标成论文发表当年的历史指标。

可启用「导入或修改发表来源后自动在线匹配」，也可匹配选中文献、当前筛选结果或全库。手动值优先，自动填充值记录来源、版本和查询时间；修改期刊后清除原期刊的旧自动值，手工修改的字段保持锁定。首次改写前的原笔记保存在 `research-vault/.workbench/metrics-backup/`，API 密钥和指标缓存位于用户数据目录，不进入论文 Markdown 或 BibTeX 导出。

PDF 阅读器同样使用工作台的纸色、衬线文献标题、圆角按钮与阅读笔记面板。单行工具栏提供翻页、缩放、高亮、批注、便签与截图摘录；文字选区操作在选中原文后启用。阅读笔记可收起，窄屏时以浮层显示，保留批注、目录、全文搜索、标签筛选与原 PDF 定位。界面适配位于 `src/port/reader-ui.js` 与 `src/port/reader.css`，原 MuPDF 渲染、标注坐标、颜色及摘录存储逻辑沿用迁移的实现。

划词翻译支持先选词再打开浮窗，暂停自动翻译时可直接点击「翻译」，开启后短词和缩写也能自动处理。浮窗内可切换目标语言、Google Web / DeepL / OpenAI-compatible，并直达设置；失败可重试，30 秒超时，连续选区会停止旧结果的等待并跳过尚未发出的旧请求。切换自动模式、固定窗口或调整标注设置不会清空译文缓存；返回文献库时，未固定的浮窗自动收起。默认仍保留自动翻译暂停状态。网络响应、超时、流式和桌面 IPC 回归见 `src/test/e2e/translation.spec.js`，使用模拟服务和独立配置，不依赖真实账户或密钥。

- 文献工作区：左侧按阅读队列、科研课题、文献集、研究主题组织；中间搜索、筛选、排序和多选文献；右侧集中展示论文信息、研究笔记与 PDF 摘录。文献页与其他模块共用工作台导航的收纳状态。
- 直接在详情中调整状态、评分、项目 / 文献集 / 主题，编辑元数据和 Markdown 笔记。支持批量状态修改、BibTeX 导出和 PDF 拖入；原文、笔记、标注仍使用现有本地存储。
- 图表摘录视图汇总论文关联图片与 PDF 区域截图；「阅读记录」同时保留尚未关联文献条目的旧批注，原 PDF 缺失时仍可查看已有文字与截图。双击论文或点击「阅读 PDF」打开阅读器，返回时保留搜索、分类和列表位置。
- 窄屏下分类进入抽屉，列表与详情单独显示；手机宽度使用双行文献列表。保留紧凑行高、详情收起与排序偏好。

- 保留原插件的文献解析、组织、引用生成与维护能力；常用评分、组织、笔记与图集已接入新界面，维护工具和迁移入口位于「更多文献工具」。原有列宽、保存视图等设置保留在插件数据中，本版新表格使用自己的固定列与排序偏好。
- MuPDF 阅读：本地 WASM 渲染、双栏选区、高亮与下划线、批注 / 标签 / 关键便签、区域摘录、大纲、全文搜索、阅读位置与缩放恢复。保留原 PDF 坐标数据，不重写源 PDF。
- 点击「迁移 Obsidian 数据」选择原 Vault，复制指定研究文件夹、Markdown 中关联的 PDF / 图片和原阅读器分片存储；不修改源 Vault、不覆盖已有论文文件、不复制原 API 密钥。原库缺失文件列入迁移报告。
- Electron 将数据保存为自己用户数据目录下的 `research-vault/` 普通文件。可点击「数据文件夹」整体备份；旧 JSON 备份仍仅覆盖基础工作台记录。
- 浏览器预览使用独立 IndexedDB 文件适配器，可以导入和阅读新 PDF；原 Vault 的本机复制迁移需使用 Electron 桌面版。
- 早期基础库保留为兼容入口，已有条目首次启动时复制为 Markdown/YAML 与 PDF。状态、标签和笔记保留，原始基础库数据不删除。
- 自动翻译初始关闭，在线元数据和翻译设置需在新应用中重新配置；默认迁移与阅读不发送原文。easyScholar 指标查询已用用户授权的接口验证；翻译等其他服务未做真实账号付费调用验证。
- Windows 本地入口：双击项目内的「启动科研工作台.cmd」或运行 `npm run start:research`，使用已构建的本地界面，无需启动开发服务。修改界面后先运行 `npm run build`；需要热更新时使用 `npm run dev:research`。
- 两种入口共用项目内被 Git 忽略的 `.local-profile/`，保留已迁移的数据。关闭窗口后默认留在托盘，单击托盘图标或再次运行启动入口即可唤出窗口；最小化的窗口也会恢复。
- 本地构建更新后，再次唤出窗口会检查并重新加载已变化的界面文件；也可通过托盘的「重新加载界面」或 `Ctrl+Shift+R` 手动刷新。刷新界面不清理文献或笔记数据。重复启动只唤出已有窗口，未取得单实例锁的进程不会再创建临时窗口。

本迁移版包含 AGPL-3.0-or-later 的阅读器和 MuPDF，按该许可证保留完整许可证及来源声明。原工作台 MIT 声明另存于 `licenses/Research-Workbench-MIT.txt`；MuPDF 原始许可证在 `public/mupdf/LICENSE`。这些改动尚未迁移至 `macos/` 独立源码。

### 📚 文献库

- 在侧边栏进入「文献库」，选择或拖入多个 PDF；文件副本和文献条目保存在当前设备的 IndexedDB，刷新或重启后可继续访问
- 按文件内容去重；导入结果分别列出成功、重复和失败文件，单个 PDF 上限 100 MB

- 管理「待阅读 / 阅读中 / 已粗读 / 已完成」状态，支持多选后批量修改

## 快速开始

1. 从 [GitHub Releases](https://github.com/Layman-art/Research-Workbench/releases/latest) 下载 `Research-Workbench-Setup-release-x64.exe`。
2. 运行安装程序并选择安装位置。普通用户无需安装 Node.js。
3. 首次启动会载入一组可编辑的科研示例数据，可以先用它熟悉项目、待办与日程。
4. 正式使用后，建议定期在「设置与数据 → 数据管理」中导出 JSON 备份。

macOS（Apple Silicon）用户可在同一 [Release](https://github.com/Layman-art/Research-Workbench/releases/tag/release) 下载 `Research-Workbench-macOS-arm64.dmg`，打开后将应用拖入「应用程序」文件夹。首次启动与源码构建说明见 [`macos/README.md`](./macos/README.md)。

默认情况下，关闭主窗口后应用仍会驻留系统托盘。需要彻底退出时，可右键托盘图标选择「退出」，也可以在设置中关闭后台运行。

> [!IMPORTANT]
> 当前 Windows 安装包尚未进行代码签名，系统可能显示「未知发布者」提示。请只从本仓库的 Releases 页面下载，并在安装前核对对应版本发布说明中的 SHA-256。

在 PowerShell 中校验安装包：

```powershell
Get-FileHash .\Research-Workbench-Setup-release-x64.exe -Algorithm SHA256
```

## 数据与隐私

Research Workbench 当前没有账号系统或云同步。项目、记录、内容类型、工作区和显示名保存在应用本机存储中；Windows 使用 Electron 用户数据目录，macOS 使用应用数据目录中的 SQLite 数据库。

JSON 备份需要手动导出，且不包含新增文献库的条目和 PDF。换机或重装前请备份项目记录并另存所需 PDF。当前版本不提供自动备份、跨设备同步或应用层加密。

<details>
<summary><strong>当前版本的能力边界</strong></summary>

- 提供 Windows x64 与 macOS Apple Silicon 发行版。
- 面向单机、单用户场景，不含云同步和实时协作。
- 「文件资料」用于记录文件位置和说明，不托管文件本体。
- 本分支新增文献库仅接入 Windows / React 版本，保存 PDF 副本；macOS 独立源码暂未接入。
- 正文为纯文本记录，不是富文本或 Markdown 编辑器。
- 暂无自动备份、自动更新和应用层数据加密。

</details>

### 文献列表备注

列表的“标签”后新增“备注”列，直接显示现有 `note` 字段。点击单元格可原位编辑，Enter 或点击其他位置保存，Esc 取消，Shift+Enter 换行；长内容省略显示，悬停可查看全文。备注参与文献搜索，列宽与显示开关沿用并记住现有列布局。空备注在窄屏隐藏以保留原有密度。

写入通过论文文件的 frontmatter 队列，只更新简短备注，保留研究笔记正文及并发标签、元信息更新。写入失败保留当前输入，可再次提交。

右侧论文详情顶部的标签下方、阅读 PDF 按钮上方也可直接编辑同一份备注。详情完整换行显示文字和胶囊，空值显示“添加备注”。编辑时 Enter 换行，点击其他位置、Ctrl/Cmd+Enter 或 Ctrl/Cmd+S 保存，Esc 取消；与列表同步，关闭或重新打开后保留。

备注支持普通文字和胶囊混排，例如 `优先阅读 [重点]{红} [待复现]{蓝}`。配色支持红 / 蓝 / 绿 / 黄（橙）/ 紫 / 青 / 灰 / 棕及对应英文名，也支持 `[自定义]{#d96c46}` 或三位十六进制色；自定义色会配成浅底与可读的深色文字。点击后仍编辑原始语法，保存和重启后保留，搜索可匹配显示的文字。普通 `[引用]`、Wiki 链接和无效语法保持文本；输入 `\[重点]{红}` 可显示字面示例。

### 论文研究笔记

文献详情的“笔记”改为所见所得 Markdown 编辑器，可独立展开；PDF 工具栏的“研究笔记”打开并排写作面板，拖动左边缘可调整宽度并记住设置。研究笔记沿用论文 Markdown 文件正文，PDF 高亮、便签、批注和截图仍单独保存。原批注侧栏标题明确为“PDF 批注”。

支持标题、加粗、斜体、删除线、引用、列表、任务列表、代码、表格、链接和 LaTeX 公式，保留 Markdown 源码切换、导入（追加）、导出、撤销 / 重做及 Ctrl/Cmd+S。正文采用文章排版，界面按钮复用工作台字体、尺寸和图标。编辑器及公式资源随应用本地打包。研究笔记正文参与文献库搜索。

自动保存与论文元信息更新共用逐文件写入队列，保存失败保留草稿并支持重试；关闭写作窗口、返回文献库前等待保存。连续输入合并更新恢复草稿，通常在输入暂停后处理，持续输入最多每秒捕获一次；输入法组词期间不运行定时捕获。关闭、导出、切换源码及退出检查前立即捕获最新正文，避免最后几个字尚在防抖周期内。已有外部正文变更会阻止旧草稿覆盖，可导出草稿后处理。草稿恢复依赖当前设备的本地浏览器存储。

笔记打开时只渲染一次正文并建立一次初始撤销记录。内嵌 Base64 图片通过 `src/port/note-images.js` 在编辑期间转换为临时图片资源，避免图片编码反复参与 Markdown 解析和撤销差异计算。保存、源码模式与 Markdown / HTML 导出仍还原原始图片编码；代码示例和普通链接的字面内容不改变。编辑器关闭后释放临时资源，不迁移原笔记或压缩图片。


### 笔记特殊标记

研究笔记单行工具栏新增调色盘“特殊标记”。选中文字后可应用标注块或文字样式；没有选区时可在面板中填写内容并插入。支持重点、疑问、方法、结论、证据、警告、灵感、总结八类标注块，以及侧线 / 描边 / 淡底三种外观。文字样式支持底色、文字色、描边、下划线，八套柔和配色、自定义十六进制色值和圆角。点击已有标记后可修改或移除，取消不写入正文。

标注块保存为 Obsidian 风格的 Markdown，例如：

```md
> [!method-outline] 复现路径
>
> 对齐训练配置，保留 **实验设置** 与证据。
```

所见所得模式可直接用调色盘插入标注块；在源码模式输入上述引用语法时，不包含外层代码围栏。若 Callout 示例已被粘成代码块，点击代码块内的文字后打开调色盘，标题和正文会自动填入，点击“转为标注块”可原位转换，支持取消与撤销。普通代码不会自动转换。只有标题的 Callout 也支持渲染和保存，不通过添加隐藏正文占位符实现。

行内标记保存为 HTML / CSS，可从源码模式直接编辑，例如：

```html
<span style="color:#2d6a60;background-color:#edf6f3;border:1px solid #6a9d91;padding:0 3px;border-radius:4px;">关键证据</span>
```

也可使用 `==原生高亮==`，或预设 CSS 类 `<span class="rw-note-inline tone-teal mode-outline">关键证据</span>`。配色类包括 amber / teal / blue / sage / rose / plum / slate / stone，外观类包括 mode-highlight / mode-text / mode-outline / mode-underline。预设类的显示依赖工作台样式；界面生成的行内 CSS 会随 Markdown 导出保留。

HTML 显示与导出适配位于 `src/port/note-markup.js`，不修改 Vditor 源码。保留文字、底色、边框、内边距、圆角、字重、斜体和文字装饰等行内样式；不允许这些笔记标记改变整个应用布局。

### 论文附录与补充材料

论文详情新增“附录”页，也可右键论文选择“管理附录”。支持批量选择文件、拖入附录区域，以及在论文列表展开附件后添加。附录归属当前论文，不会创建新的文献条目。支持补充 PDF、Word、Excel、CSV、图片和 ZIP 等文件；PDF 使用原 MuPDF 阅读器，其他文件可下载。每个文件不超过 100 MB。

附录可编辑名称，按附录 / 补充方法 / 补充图表 / 数据 / 其他分类，通过右键菜单调整顺序、下载或移除关联。相同内容自动去重；不同内容即使同名也分别保存。附件副本保存在应用本地数据目录，关联写入论文 Markdown 的 `supplementary_files` 字段，与元信息、研究笔记共用文件写入队列。

阅读器中的“正文 / 附录”切换对应论文的 PDF，保留每个文件各自的阅读位置、逐页时长、高亮、批注与截图摘录。附录摘录归入对应论文，显示来源文件名；正文标题热图与逐页统计仍只统计正文，附录页显示各文件自己的时长和摘录数。研究笔记与整篇论文关联，在正文和附录之间共享。移除关联不会删除本地文件或原阅读记录；重新添加相同文件可恢复原文件路径和标注关联。

### 正文与附录并排阅读

在附录 PDF 行点击“与正文并排阅读”，或在阅读器的“正文 / 附录”菜单选择“正文与附录并排阅读”。两栏独立翻页、缩放和标注，可从栏头切换其他附录；共享研究笔记保持当前编辑模式。拖动中间分隔线调整比例，设置会在本机记住；双击分隔线恢复均分，也支持方向键调整和 Home 均分。窄窗口自动上下对照，并单独记住高度比例。

点击或操作哪一栏，PDF 批注侧栏、逐页统计和阅读计时就跟随哪一栏，避免两份文件同时累加时长。关闭一栏会保留另一栏的阅读位置，重新打开后各文件的阅读位置和标注仍分别恢复。适配位于 `src/port/pdf-comparison.js`，复用原 MuPDF 阅读器实例，不修改导入的 PDF 引擎源码。

### 笔记与论文定位

研究笔记与 PDF 可以按标题、图表和段落定位点双向跟随。PDF 与笔记并排时，在笔记标题或段落上右键选择“关联当前 PDF 位置”，也可在 PDF 的相应位置右键选择“关联到研究笔记…”并选择标题或新建标题。笔记工具栏的链条图标提供相同操作。

PDF 工具栏的“图表插入研究笔记”图标支持框选图表，截图会插到当前笔记块后并自动保留来源。已有区域摘录也能右键插入研究笔记。点击笔记中的小跳转标记或截图回到对应 PDF 页内位置，并短暂突出来源区域。解除关联保留图片和正文，支持撤销与重做。

工具栏双向箭头开关控制滚动联动，并记住设置。滚动停顿约 200ms 后跟随最近定位点，一个定位点覆盖到下一个定位点；正文和附录按各自文件区分。自动联动只跟随当前已打开的对应 PDF，点击跳转标记则可以打开相应附录。没有关联的旧笔记需要先建立定位点，不按篇幅比例或未经确认的语义猜测跳转。

来源以标准 Markdown 链接的 `#rw-pdf=` 片段保存，保留 PDF 的库内路径、页码与归一化页内位置；截图链接也记录区域。链接随源码、导出和重新打开保留，应用外的 Markdown 阅读器不会执行工作台的定位联动。笔记正文与 PDF 批注仍分别管理，原 PDF 文件不被改写。

### 课题任务与过程记录

科研课题默认显示任务表，选择条目后在右侧查看详情与时间线，分隔线可拖动调宽并记忆。原有概览、关联论文、点子、实验、数据与时间线位于“课题资料”。任务可搜索、按状态和类别筛选、排序及多选修改状态。类别作为组合标签显示。

“标签与字段模板”可修改大类/小类、语义色及事件模板，字段支持增删、改名、排序、类型和必填设置。事件保存字段名称及类型快照；后续修改模板不会重写历史记录。相关文件可导入或关联已有课题文件，支持预览和下载，PDF 复用阅读器。关联内容可保存论文、链接与 Markdown 研究笔记，讨论和备注单独保留。

任务操作菜单提供新任务 Prompt，任务详情提供更新 Prompt。将 Prompt 交给正在执行工作的 Codex，再把返回的 JSON 粘贴到记录窗口，预览后导入。协议 `research-workbench.task.v1` 使用稳定的课题、任务、请求及事件 ID；更新只追加事件，同一输出重复粘贴不会重复创建。发生时间采用带时区的 ISO 8601，界面按 Asia/Shanghai 显示；无法核实时保留 null。记录写入时间另存，创建任务记录不冒充执行开始的状态变更。历史事件按实际时间推导进展，未知时间的状态属于写入时报告的状态，界面仍显示“时间待确认”。

本地数据版本为 8，自动兼容旧课题记录。JSON 备份包含任务、事件和字段模板，二进制文件仍保留于文献库 vault；迁移与复制不改变原始文献/PDF。当前接入方式为 Prompt 和粘贴 JSON，不会自动读取其他 Codex 会话。

课题工作区首次打开和重载后进入“课题总览”，按课题显示任务数与进行中数量，下面汇总全部任务。点击课题行或顶部选择器进入独立任务表，“课题总览”可随时返回；工作区筛选在有多个工作区时可直接调整。总览中新建任务及生成新任务 Prompt 必须明确选择所属课题；粘贴记录按 JSON 中的课题 ID 归属，并在预览中显示课题名称。每个课题独立保存自己的任务与时间线，同一会话内的总览/课题切换状态独立于资料页选择，不会被旧选择覆盖。

课题总览支持收起目录、重点优先，以及右键创建任务、生成定向 Prompt、编辑、复制、设置状态和归档；已归档课题从任务操作菜单进入，可在资料目录恢复。任务支持从行菜单或多选操作条移动到其他课题，跨工作区也可选择目标。移动保留稳定任务 ID、时间线、笔记、讨论、论文与文件关联，源文件不搬动，原课题中的共享文件仍保留；文件索引 ID 冲突时自动重新映射。移动前会捕获正在编辑的课题笔记，批量状态更新统一提交一次，已有同状态的记录不重复追加事件。桌面详情可关闭，收起详情后表格恢复可用的日期列。
